# Authorship and attribution

This repository is a curated portfolio version of an academic project completed in a three-person group within the **Control** course of the BSc in Electrical and Computer Engineering at Instituto Superior Técnico (2025/2026).

The published MATLAB scripts document Rómulo Yan's contribution to data processing, modelling, controller design, experimental-result analysis and figure generation.

Some laboratory acquisition and plotting utilities were supplied by the course team for use with the Arduino-based experimental platform. Those files are intentionally omitted from this repository and are not claimed as original work.

The repository does not include the original submitted reports, course handouts, classmates' contact details, student numbers or backup archives.
